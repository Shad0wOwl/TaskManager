# TaskManager

A full-stack task management web application built with **Java, Spring Boot, and PostgreSQL**, featuring a responsive interface and secure user authentication.

## Status

🚧 **Work in Progress** — Core functionality is implemented. Testing and deployment are planned.

## Features

- User registration and login
- Automatic login after registration
- Session-based authentication with Spring Security
- Secure password hashing using BCrypt
- Create, view, edit, and delete tasks
- Track task progress through status updates
- User-specific task management
- Persistent data storage with PostgreSQL
- Responsive interface with dark theme

## Tech Stack

**Backend**
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA / Hibernate
- Maven

**Frontend**
- HTML5
- CSS3
- JavaScript (Vanilla JS)

**Database**
- PostgreSQL
